# DataWhisper Screenshots

This folder holds product screenshots referenced by the root `README.md`.

## Required images

Add PNG screenshots with these exact filenames:

| File | What to capture |
| ---- | --------------- |
| `landing.png` | Landing page — hero section, value proposition, and primary CTAs |
| `auth.png` | Login or register page — form layout and product value panel |
| `dashboard.png` | Dashboard overview — KPI cards, health score, charts, and category summary |
| `upload.png` | CSV / Excel upload flow — file picker, detected columns, and analysis status |
| `ai-analysis.png` | AI business analysis — question input and structured insight response |

## Guidelines

- Use the **live deployment** or local dev with representative demo data.
- Prefer **desktop viewport** (1280px or wider) for consistent README layout.
- Keep filenames lowercase with hyphens as listed above.
- Do not commit screenshots containing real customer data, API keys, or personal information.
- PNG format is recommended for crisp UI text in GitHub.
