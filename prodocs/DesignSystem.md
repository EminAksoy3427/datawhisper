# DataWhisper Design System

## Design Goal

DataWhisper should feel:

- Simple
- Modern
- Business-focused
- Beginner friendly
- Clean and not overwhelming

Target users are small business owners, so the interface should avoid technical complexity.

---

## Color Palette

### Primary

- Blue: #2563EB

Used for:

- Main buttons
- Active elements
- Links
- Important highlights

### Secondary

- Emerald: #10B981

Used for:

- Success states
- Positive metrics
- Healthy business indicators

### Warning

- Orange: #F59E0B

Used for:

- Medium risk
- Alerts
- Attention areas

### Danger

- Red: #EF4444

Used for:

- High risk
- Negative indicators
- Errors

### Neutral

- Background: #F8FAFC
- Card: #FFFFFF
- Border: #E5E7EB
- Text: #1E293B

## UI Rules

- Maximum width: 1200px
- Use cards for sections
- Avoid crowded layouts
- Use loading indicators
- Show friendly error messages
- Keep language simple
